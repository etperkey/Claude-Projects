ISSUE 1: DOUBLE-HIT LYMPHOMAS (CRITICAL)
================================================================================

PROBLEM:
5 known double-hit DLBCL cell lines are incompletely represented in the fusion 
dataset. Double-hit lymphomas have both BCL2-IGH AND MYC-IGH translocations 
(or BCL6-IGH + MYC-IGH), representing a high-risk subtype.

AFFECTED CELL LINES:
  1. OCI-LY-18 (ACH-001616)        - NOT IN DATASET (name lookup failed)
  2. SU-DHL-10 (ACH-000271)        - Missing BOTH BCL2 and MYC
  3. DOHH-2 (ACH-000056)           - Missing MYC (has BCL2)
  4. VAL (ACH-001703)              - Missing MYC (has BCL2)
  5. Toledo (ACH-000285)           - Missing BOTH BCL2 and MYC

ROOT CAUSES:
  - OCI-LY-18: Cell line name not found in DepMap RNA-seq fusion file
  - SU-DHL-10, Toledo: No fusion data in either RNA-seq or curated sources
  - DOHH-2, VAL: BCL2-IGH detected by RNA-seq, but MYC-IGH missed due to 
    RNA-seq caller limitation (breakpoints in non-coding regions like 3' UTR)

SOLUTION:
  Add 7 curated fusion entries to scripts/build_fusions.py, lines 49-55
  
  Required additions:
    - SU-DHL-10: BCL2--IGH, MYC--IGH
    - Toledo: BCL2--IGH, MYC--IGH
    - DOHH-2: MYC--IGH (BCL2 already exists)
    - VAL: MYC--IGH (BCL2 already exists)
    - OCI-LY18: MYC--IGH

  See FUSION_FIX_INSTRUCTIONS.md for exact code to add.

IMPACT:
  - Data completeness: 60% → 100% for known DHL lines
  - User understanding: Better representation of high-risk DLBCL
  - Visualization: Currently red-shaded cells will appear in MYC and BCL2 rows
